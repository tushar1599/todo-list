# 📝 Premium Todo List (React + Bootstrap)

A simple and elegant todo list built with React, using localStorage to persist data and Bootstrap 5 for a premium look.

## 🚀 Features

- Add, edit, delete tasks
- Filter: All / Active / Completed
- Clear all tasks
- Tasks saved to browser (localStorage)
- Responsive & premium UI

## 📦 How to Run

```bash
npm install
npm start
